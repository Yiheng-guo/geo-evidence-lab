# 为什么重做效果验证

维护者：郭一恒（Yiheng Guo）。本项目的产品判断是：GEO 工具应帮助用户减少不可验证的效果宣称，而不仅仅增加内容产量。

本地分析过的工作流整合包覆盖客户档案、关键词、写稿、平台改写和豆包研究，适合作为业务流程参考。但未发现 LICENSE 或明确的再分发授权，因此不直接搬运或重新许可原文件。

新的实现采用自己的 JSON 数据契约、配对分析算法与报告界面。重点设计：

- 冻结问题和品牌档案，防止后测更换问题导致虚假提升。
- 引擎、模式、上下文、轮次匹配，不将不同条件直接混为前后变化。
- 缺失和失败显式排除，零样本不会返回 0% 或成功。
- 提及与自有域名引用分别报告；有来源不等于来源支持品牌。
- HTML 转义导入内容，URL 限定 HTTP(S)，不执行原始回答中的脚本。
- 留存输入摘要和原始回答，便于人工复核；摘要不是真实性认证。

当前没有内置平台规则表，因为规则需要持续核实；没有机械关键词密度要求，因为本项目没有其提高 AI 可见性的验证证据；没有自动发稿，避免把写作任务产物误称成公开发布。

为了减少起步成本，v0.1 使用 Python 标准库，无账号、无 API Key、无遥测、无外部 JavaScript。任何真实数据的公开分享应由用户判断授权范围；本仓库仅附带明显标注的模拟品牌与模拟回答。
